# clinica-fisio
Sistema gerenciador Fisioterapia Clínica.

## O projeto

O arquivo `PRD_PROJETO.md` contém as especificações do projeto. 
O arquivo `ESPECIFICACOES_TECNICAS.md` contém as especificações técnicas do projeto.
O arquivo `IDENTIDADE_VISUAL.md` contém as especificações visuais do projeto.
O arquivo `ARQUITETURA_BACKEND.md` contém as especificações arquiteturais do backend.

## Tecnologias envolvidas

* JavaEE
* JSF Primefaces
* PostgreSQL
